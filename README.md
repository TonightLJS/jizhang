# 随手记账 App

iPhone 上使用的记账 / 分账 / 统计工具，纯前端 PWA，数据本地优先 + Supabase 云端同步。

直接打开 `index.html` 或用任意静态托管（GitHub Pages / Netlify / Vercel）即可运行。

## 功能

- **记账 / 收入**：多账本、多货币与汇率、优惠、预算，**日期时间精确到分钟**
- **删除**：任意一笔可删除（会同步到其它设备，云端不会复活）
- **退款**：支持全额退与部分退款，可撤销
- **分账**：多人分摊、结算清账
- **统计**：月度趋势、分类占比、账户余额
- **云端同步**：Supabase（本地优先 + 云镜像）
- **快捷指令记账**：一句话自动识别金额/分类/日期/**时间**并记账，支持 Siri、主屏一键、分享面板
